# Security Policy

If you discover a security vulnerability, please do not open a public issue. Instead, contact the maintainers privately:

Email: sany2k8@gmail.com

What to include in your report:
- Clear description of the vulnerability and the affected components
- Steps to reproduce
- Impact assessment and any exploit code or proof-of-concept if available
- Suggested mitigation or patches if you have them

We will respond to security reports as soon as possible and coordinate a fix and disclosure.
